# Regulatory Intelligence Assistant

MVP d'assistance à l'analyse réglementaire : ingestion structurée, recherche sourcée,
comparaison de versions et identification prudente des impacts potentiels.

> Ce logiciel assiste l'analyse. Il ne fournit pas de conseil juridique et ne prend
> aucune décision de conformité autonome.

La documentation d'utilisation et d'architecture sera complétée avec l'implémentation.
